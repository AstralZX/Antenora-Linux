The Package Manager

DANTE

Written in Go. Source-based like Gentoo, with signed binary fallbacks. Because managing packages is a journey through Hell.

The commands.

CommandWhat it does
dante syncClone / update the official repos + the DUR (git).
dante install <pkg>Resolve deps (topological sort), then compile from source or fetch a signed binary.
dante install -A <pkg>Install from the DUR (user repository).
dante remove <pkg>Uninstall, warning about reverse dependencies.
dante remove --orphansRemove packages no longer required.
dante search <term>Search names + descriptions, official and DUR.
dante info <pkg>Metadata, dependencies, binary availability.
dante updateVersion-aware upgrade of everything installed.
dante cleanPurge cached sources and build directories.
dante toolchainBootstrap the build toolchain from source.
dante mirrorTest and rank binary mirrors by latency.
dante keyImport the Antenora maintainer GPG key.
dante durList DUR packages.
dante dur-search <term>Search the DUR only.
dante compile in.hell out.mkCompile a Hell recipe to a standalone Makefile.
dante gen-manifest <dir>Regenerate a repo's manifest.yaml from its recipes.
Configuration

/etc/dante/dante.conf

# Dante Package Manager Configuration
BINARY="NO"       # "YES" prefers signed binary packages
MAKEFLAGS="-j4"   # parallel jobs (raise only if you have the RAM)
PARALLEL="4"     # concurrent package builds

REPO_URL="https://github.com/AstralZX/antenora-packages.git"
DUR_URL="https://github.com/AstralZX/antenora-dur.git"
BINARY_MIRROR="https://cdn.antenora.org/packages"
MIRROR_FILE="/etc/dante/mirrors.conf"

CLEAN_SOURCE="YES"  # remove source after build
KEEP_DEPS="NO"    # remove deps when removing a package

Every key is also overridable per-command with a DANTE_* env var — e.g. DANTE_BINARY=YES dante install linux-cachyos-bore.

How it works.

Resolution

Topological sort

Dependencies resolve depth-first; a cycle is reported in full — a → b → c → a — and the install aborts.

Binaries

Verified or rebuilt

Download → SHA-256 → GPG signature → extract. Any failure falls back to compiling from source. Trust nothing.

Mirrors

Ordered failover

/etc/dante/mirrors.conf lists mirrors in preference order; dante mirror ranks them by latency.

Tracking

Every file known

Each install records its file list in /var/lib/dante/db. Removal is clean and warns about dependents.

Versions

Semantic compare

6.10 > 6.9, 1.0 > 1.0_rc1. dante update upgrades only what's genuinely newer.

Bootstrap

Self-hosting

Dante is a single static Go binary. It runs before glibc exists — which is how it builds glibc.
