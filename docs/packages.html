The Package Manager

DANTE & HELL

Dante is a source-based package manager written in Go. Hell is the recipe language. Managing packages is a journey through Hell.

Dante

$ dante sync # update repos + DUR
$ dante install base-system # resolve deps, compile, install
$ dante install -A hyprland # from the DUR
$ dante remove pkgname # uninstall + reverse-dep warnings
$ dante search term # search official + DUR
$ dante info pkgname # metadata + binary availability
$ dante update # version-aware upgrade
$ dante toolchain # bootstrap the build toolchain
$ dante mirror # test + rank binary mirrors
Resolution

Topological sort

Dependencies are resolved depth-first, cycles are reported in full. No package installs out of order.

Binaries

Signed & verified

SHA-256 checksum + GPG signature before any binary is trusted. On failure, it compiles from source instead.

Tracking

Every file known

Each install is recorded with its file list. Removal is clean, reverse dependencies are warned about.

The Language

Hell — a recipe in 30 seconds.

# curl.hell
package "curl" version "8.8.0" {
    source "https://github.com/curl/curl/releases/download/8.8.0/curl-8.8.0.tar.xz"
    depends "openssl" "zlib" "ca-certificates"

    arch x86_64 { cflags "-march=native -O3 -pipe" }

    build   { run "./configure --prefix=/usr --with-openssl"
               run "make -j$HELL_JOBS" }
    install { run "make install DESTDIR=$HELL_ROOT" }

    binary "https://cdn.antenora.org/packages/curl-8.8.0-x86_64.db" {
        sha256 "a1b2c3d4e5f6..."
    }
}

Whitespace-insensitive, # comments, ~20 keywords, and a hard 50-line limit — exceed it and the parser throws BLASPHEMY_ERROR. Read the full language guide.
