The Recipe Language

HELL

A minimalistic cross between Makefile and Lua, designed to be impossible to write poorly. You can learn it in five minutes — and if a recipe exceeds 50 lines, the parser refuses to run it.

A recipe in 30 seconds.

# curl.hell
package "curl" version "8.8.0" {
    source "https://github.com/curl/curl/releases/download/8.8.0/curl-8.8.0.tar.xz"
    depends "openssl" "zlib" "ca-certificates"

    arch x86_64 { cflags "-march=native -O3 -pipe" }

    build   { run "./configure --prefix=/usr --with-openssl"
               run "make -j$HELL_JOBS" }
    install { run "make install DESTDIR=$HELL_ROOT" }

    binary "https://cdn.antenora.org/packages/curl-8.8.0-x86_64.db" {
        sha256 "a1b2c3d4e5f6..."
    }
}

Four things: package + version (identity), source (the tarball), build (compile), install (place files). Everything else is optional.

The rules.

  • ◆  # starts a comment — everything after it to the end of the line.
  • ◆  Strings are "double quoted"; \ escapes a character.
  • ◆  Indentation is style. The parser ignores whitespace.
  • ◆  One package per file, named <package>.hell.
  • ◆  Over 50 lines → BLASPHEMY_ERROR. The parser refuses.

The keywords.

DirectiveMeaning
package "n" version "v"Required. Package identity.
description "..."One-line summary shown by dante search.
source "url"Tarball to download (.tar.gz/.tar.xz/.tar.bz2).
depends "a" "b"Dependencies — resolved automatically.
build { ... }Compile steps.
install { ... }Install steps.
post_install { ... }Runs once after install (links, caches, config).
binary "url" { ... }Optional signed binary fallback.
arch x86_64 { ... }Architecture-specific flags.

Conditions:

if arch_x86_64 { run "..." } else { run "..." }
if binary_available { run "..." }
if file_exists "/etc/foo" { run "..." }
if env "SOME_VAR" { run "..." }

Build patterns.

Autotools
build { run "./configure --prefix=/usr"
         run "make -j$HELL_JOBS" }
install { run "make install DESTDIR=$HELL_ROOT" }
Meson
build { run "meson setup build --prefix=/usr"
         run "ninja -C build" }
install { run "ninja -C build install --destdir $HELL_ROOT" }
CMake
build { run "cmake -B build -DCMAKE_INSTALL_PREFIX=/usr"
         run "cmake --build build -j$HELL_JOBS" }
install { run "cmake --install build --prefix $HELL_ROOT/usr" }
Go
build { run "go build -trimpath -o tool ." }
install { run "install -Dm755 tool $HELL_ROOT/usr/bin/tool" }
Rust
build { run "cargo build --release --locked" }
install { run "install -Dm755 target/release/tool $HELL_ROOT/usr/bin/tool" }
Config-only
build { run "true" }
install { cp "config" "$HELL_ROOT/etc/tool.conf" }
