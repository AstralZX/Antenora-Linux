Canto I · The Descent

A Linux distribution with no compromises.

Antenora is built from raw source by its own package manager, booted by s6, on glibc and XFS, with a kernel tuned for the ninth circle. No systemd. No Arch. No bloat. No mercy.

I

s6 init

systemd is forbidden. Every service is a script, supervised by s6-rc. Boot is measured in milliseconds.

II

Dante & Hell

A package manager written in Go, driving packages described in Hell — a recipe language impossible to write poorly.

III

linux-cachyos-bore

1000 Hz, preempt-dynamic, the BORE scheduler, -O3 -march=native. Minimal latency, maximum FPS.
