The Dante User Repository

THE DUR

The ninth circle is a democracy of recipes. The DUR is a public repository anyone can commit to.

Trust nothing. Review everything.

Like the AUR, the DUR holds build recipes, not binaries. Any user may submit a .hell recipe; maintainers review and may promote stable packages into the official repositories.

Submit

One command

scripts/dur-submit.sh my-package.hell clones the DUR, adds your recipe, and pushes it.

Install

From anywhere

dante install -A my-package pulls and builds it, resolving deps from official + DUR.

Ascend

Be promoted

Well-maintained recipes graduate into antenora-packages. Treachery rewarded.

The Rite

Contribute in three steps.

Write the recipe

Start from docs/recipe-template.hell. Keep it under 50 lines.

Validate it

dante compile my-package.hell - — if it parses, it's worthy.

Ship it

dur-submit.sh my-package.hell, or open a pull request under recipes/.

$ dante dur # list DUR packages
$ dante dur-search sway # search the DUR
$ dante install -A hyprland
The Law

The rules of the pit.

  • ◆  A recipe must be 50 lines or fewer — BLASPHEMY_ERROR otherwise.
  • ◆  Recipes build from source; no prebuilt blobs unless a signed binary fallback declares a SHA-256.
  • ◆  No malware, no miners, nothing that would embarrass the ninth circle.
