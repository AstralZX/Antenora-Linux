THE ANTENORA HANDBOOK

From a blank disk to a fully installed, self-compiled system. The whole journey, one page.

Part I — Installing Antenora

1 · Introduction & requirements

Antenora is a source-based distribution. The base system is compiled from source by Dante, its package manager. The init system is s6 + s6-rc (systemd is forbidden), the libc is glibc, the root filesystem is XFS.

You need: an x86_64 machine (UEFI or BIOS), a live medium, network, ≥ 4 GB RAM, ≥ 20 GB disk, and a root shell.

Conventions: /dev/sda is the disk, /dev/sda1 the EFI partition, /dev/sda2 root. Replace them with your own.

2 · Choosing the installation medium

Three ways in: the Antenora live ISO (blessed), any Linux live system (you only need tar, xfsprogs, chroot), or an existing Linux install.

$ make iso        # build the ISO from source

3 · Configuring the network

The live environment uses NetworkManager.

# nmtui                                        # text UI — easiest
# nmcli device wifi connect "SSID" password "pass"
# dhclient                                     # wired
# ping -c3 example.com

4 · Preparing the disks

# ls /sys/firmware/efi/efivars                 # exists → UEFI
# cfdisk /dev/sda
SchemePartitions
UEFI + GPTsda1 EFI (FAT32, 300M) · sda2 root (XFS)
BIOS + MBRsda1 root (XFS)
BIOS + GPTsda1 BIOS boot (1M) · sda2 root (XFS)

5 · Formatting the filesystems

The Third Commandment: root is XFS.

# mkfs.xfs -f -n ftype=1 -d inode64 /dev/sda2
# mkfs.fat -F32 /dev/sda1                       # UEFI

Optional LUKS encryption:

# cryptsetup luksFormat /dev/sda2
# cryptsetup open /dev/sda2 root
# mkfs.xfs -f -n ftype=1 -d inode64 /dev/mapper/root

6 · Mounting

# mount /dev/sda2 /mnt
# mkdir -p /mnt/boot && mount /dev/sda1 /mnt/boot

7 · Installing the Stage3

The Stage3 is the self-hosting base: s6, glibc, and Dante — the bootstrap solved for you.

# wget https://github.com/AstralZX/Antenora-Linux/releases/latest/download/stage3-1.0.0-x86_64.tar.xz
# tar -xJpf stage3-1.0.0-x86_64.tar.xz -C /mnt --numeric-owner

8 · Chrooting

# cp /etc/resolv.conf /mnt/etc/resolv.conf
# mount --bind /dev /mnt/dev && mount --bind /dev/pts /mnt/dev/pts
# mount --bind /proc /mnt/proc && mount --bind /sys /mnt/sys && mount --bind /run /mnt/run
# chroot /mnt /bin/bash

9 · Configuring the system

# echo "antenora" > /etc/hostname
# ln -sf /usr/share/zoneinfo/Europe/Berlin /etc/localtime
# locale-gen
# echo 'LANG=en_US.UTF-8' > /etc/locale.conf

Write /etc/fstab for your partitions.

10 · Installing packages

# dante sync
# dante install base-system
# dante install linux-cachyos-bore linux-firmware
# dante install sway        # plasma / gnome / sway — or none

11 · Configuring the bootloader

# /usr/lib/antenora/s6-init-setup.sh
# /usr/lib/antenora/mkinitramfs.sh / /boot/initramfs-antenora.img boot/disk-boot/init
# grub-install --target=x86_64-efi --efi-directory=/boot --bootloader-id=Antenora
# grub-mkconfig -o /boot/grub/grub.cfg

12 · Finalizing

# useradd -m -G wheel -s /usr/bin/zsh you
# passwd you && passwd root
# echo '%wheel ALL=(ALL:ALL) ALL' > /etc/sudoers.d/10-wheel
# su - you && ssh-keygen -t ed25519 -C 'you@antenora' && exit

13 · Rebooting

# exit && umount -R /mnt && reboot

First boot: ZRAM (lz4), SSH keys, nftables firewall. A winged lion appears.

Part II — Working with Dante

14 · Package management

dante sync               # update repos + DUR
dante install <pkg>       # resolve deps, compile, install
dante install -A <pkg>    # from the DUR
dante remove <pkg>        # uninstall + reverse-dep warnings
dante remove --orphans
dante search <term>
dante info <pkg>
dante update
dante clean
dante toolchain
dante mirror
dante key
dante dur
dante dur-search <term>
dante compile in.hell out.mk

15 · The Hell language

Packages are written in Hell (.hell) — ~20 keywords, a 50-line cap, impossible to write poorly. Read the full guide →

16 · The DUR

scripts/dur-submit.sh my-package.hell   # contribute
dante install -A my-package             # install

17 · Configuration & mirrors

BINARY="NO"        # "YES" prefers signed binary packages
MAKEFLAGS="-j4"    # parallel jobs
REPO_URL="https://github.com/AstralZX/antenora-packages.git"
DUR_URL="https://github.com/AstralZX/antenora-dur.git"
BINARY_MIRROR="https://cdn.antenora.org/packages"
MIRROR_FILE="/etc/dante/mirrors.conf"
CLEAN_SOURCE="YES"
KEEP_DEPS="NO"

Per-command override: DANTE_BINARY=YES dante install linux-cachyos-bore. Mirrors are one URL per line; dante mirror ranks them.

18 · The toolchain

dante toolchain
scripts/toolchain.sh   # or, into a sysroot

Bootstraps linux-api-headers → gmp/mpfr/mpc/isl → binutils → gcc → make → autotools → cmake/meson/ninja.

19 · Binary packages

Binaries are SHA-256 checksummed and GPG-signed. On any verification failure, Dante refuses and compiles from source.

Part III — Working with Antenora

20 · s6 & services

s6-rc -u change <service>     # start
s6-rc -d change <service>     # stop
s6-rc -a list                 # list all
s6-start <service>            # alias
s6-stop  <service>

Services live in /etc/s6-rc/source/ — trivial scripts you can read and edit.

21 · Logging

tail -f /var/log/<service>/current

22 · Users & permissions

useradd -m -G wheel -s /usr/bin/zsh name
passwd name
usermod -aG wheel name

23 · Networking

nmtui
nmcli device wifi connect "SSID" password "pass"
nmcli device status

The nftables firewall blocks all inbound except SSH and ping, statefully.

24 · Time & localization

timedatectl set-timezone Europe/Berlin
timedatectl set-ntp true
locale-gen

25 · Performance

vm.vfs_cache_pressure = 50
vm.swappiness = 10
kernel.numa_balancing = 0

ZRAM (lz4) is automatic; the kernel runs at 1000 Hz with the BORE scheduler.

26 · Upgrading

dante sync && dante update
/usr/lib/antenora/mkinitramfs.sh / /boot/initramfs-antenora.img boot/disk-boot/init
grub-mkconfig -o /boot/grub/grub.cfg

27 · Troubleshooting

Boot fails → busybox shell. The initramfs couldn't mount root. Check root=, or xfs_repair /dev/sda2.

A package fails to build. Read the error, dante info <pkg>, file a bug.

A service won't start. s6-rc -a list <service> and read its run script and log.
