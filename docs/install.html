The Gates of Hell

INSTALL

One bootable ISO, one installer, and a machine reborn free of systemd.

Download

Grab a prebuilt ISO from the releases, or build it entirely from source with make iso.

Download the ISO Build from source
$ make iso

The Descent

The installation, step by step.

Boot the ISO

BIOS or UEFI, GRUB will hand you the Gates of Hell installer.

Partition with cfdisk

Make a root partition — and an EFI partition on UEFI systems.

Format as XFS

Root is formatted mkfs.xfs -n ftype=1 -d inode64. EFI is FAT32. No questions asked.

Extract the Stage3

The self-hosting base (s6, glibc, Dante) lands in the new root, then chroot.

Kernel & base system

linux-cachyos-bore (binary by default; source if you're a masochist) plus the base.

Choose your desktop

KDE Plasma, GNOME, SwayWM — or none, headless warrior mode.

User, sudo, SSH

Your user joins wheel, sudo is configured, SSH keys are generated.

GRUB

grub-mkconfig, a 3-second timeout, the dark red/black theme.

Reboot

A winged lion. Then the promised land.

Requirements

What you'll need.

  • ◆  A 64-bit x86_64 machine (UEFI or BIOS)
  • ◆  At least 4 GB of RAM, and disk for a real filesystem
  • ◆  A USB stick and dd — or the willingness to compile the world yourself

The installer detects your hardware (lspci, lsusb) and pulls the right firmware. ZRAM (lz4) is enabled automatically — no swap partition. The firewall allows SSH and ping, and nothing else.
