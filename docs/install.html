MANUAL INSTALL

No installer. No wizard. No "express" mode. Only you, a root shell, and the raw silicon.

Download

Boot the live ISO — or build it entirely from source.

Download the ISO Build from source
$ make iso

The Rite

The installation, by hand.

Every command below is one you typed, and therefore one you own. Conventions: /dev/sda2 is root, /dev/sda1 is EFI. Substitute your own.

Partition

cfdisk /dev/sda — a root partition, plus an EFI partition on UEFI.

Format — XFS

# mkfs.xfs -f -n ftype=1 -d inode64 /dev/sda2
# mkfs.fat -F32 /dev/sda1 # UEFI

Mount

# mount /dev/sda2 /mnt
# mkdir -p /mnt/boot && mount /dev/sda1 /mnt/boot

Extract the Stage3

# wget <stage3-url>
# tar -xJpf stage3-1.0.0-x86_64.tar.xz -C /mnt --numeric-owner

chroot

# cp /etc/resolv.conf /mnt/etc/resolv.conf
# mount --bind /dev /mnt/dev && mount --bind /proc /mnt/proc && mount --bind /sys /mnt/sys
# chroot /mnt /bin/bash

Configure

# echo antenora > /etc/hostname
# ln -sf /usr/share/zoneinfo/Europe/Berlin /etc/localtime

Write /etc/fstab for your partitions.

Install the world

# dante sync
# dante install base-system linux-cachyos-bore linux-firmware
# dante install sway # plasma / gnome / sway — or none

Initramfs & init

# /usr/lib/antenora/s6-init-setup.sh
# /usr/lib/antenora/mkinitramfs.sh / /boot/initramfs-antenora.img boot/disk-boot/init

Bootloader

# grub-install --target=x86_64-efi --efi-directory=/boot --bootloader-id=Antenora
# grub-mkconfig -o /boot/grub/grub.cfg

User, sudo, SSH

# useradd -m -G wheel -s /usr/bin/zsh you
# passwd you && passwd root
# echo '%wheel ALL=(ALL:ALL) ALL' > /etc/sudoers.d/10-wheel

Reboot

# exit && umount -R /mnt && reboot
First Boot

What happens on your first descent.

ZRAM (lz4) is enabled automatically — no swap partition. The nftables firewall blocks everything inbound except SSH and ping. /usr/lib/antenora/firstboot.sh generates missing SSH keys. Then a winged lion.
