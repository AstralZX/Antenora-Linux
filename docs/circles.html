THE NINE CIRCLES

The Ten Commandments of Antenora, arranged — as they must be — into the nine circles of Hell.

I
Limbo · The Init Heresy

systemd is forbidden

The virtuous unbaptised were never touched by systemd. Antenora boots s6 + s6-rc — every service a trivial script. Boot to login in milliseconds, or it has failed.

II
Lust · The Passion for Speed

linux-cachyos-bore

CONFIG_HZ=1000, preempt-dynamic, the BORE scheduler, -O3 -march=native. Minimal input latency, maximum FPS.

III
Gluttony · The Rejection of Bloat

No snap, no telemetry, no daemon sprawl

Only what you compile. The package manager tracks every file. dante remove actually removes things.

IV
Greed · The Hoarding of Cycles

Performance above all

vm.swappiness=10, vfs_cache_pressure=50, ZRAM on lz4, BBR congestion control, nftables blocking all but SSH and ping.

V
Wrath · The GLIBC Oath

glibc, always

musl is for toys. Steam, NVIDIA drivers, proprietary CAD — they all work without symlink tricks. The 2% memory overhead buys 100% compatibility.

VI
Heresy · The XFS Covenant

XFS for warriors

ext4 is for people who hate their data. btrfs is for masochists. ZFS is for lawyers. Root is XFS with ftype=1 and inode64.

VII
Violence · The Hell Language

Impossible to write poorly

Packages are written in Hell (.hell). Exceed 50 lines and the parser throws BLASPHEMY_ERROR.

VIII
Fraud · Trust Nothing

SHA-256 + GPG, always

Every binary package is checksummed and signature-verified. On any failure, Dante refuses and falls back to compiling from source.

IX
Treachery · The DUR

The Dante User Repository

A public repository anyone can commit to. Submit a recipe; maintainers judge. The faithful install with dante install -A.
